### Browser redirect constraint (2026-11-12)

The prior note's suggestion to validate each redirect destination needs a browser-specific qualification: MDN documents that `fetch` with `redirect: manual` yields an `opaqueredirect` response with status 0 and empty headers, so browser JavaScript cannot inspect each Location hop that way (https://developer.mozilla.org/en-US/docs/Web/API/Response/type).
